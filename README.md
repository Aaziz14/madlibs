
# 🎭 Mad Libs Game — Python

Un jeu **Mad Libs** développé en Python dans lequel le joueur complète une histoire en fournissant différents mots : adjectifs, verbes, noms, lieux, émotions, etc.

Le programme sélectionne automatiquement une histoire parmi plusieurs thèmes et génère une version personnalisée à partir des réponses du joueur.

## 📚 Histoires disponibles

Le projet contient actuellement quatre histoires inspirées de grandes œuvres et de leurs univers :

1. 🌲 **Chronique des temps obscurs**
2. 👦 **Une vie de boy**
3. ⚖️ **Les Misérables**
4. ⚔️ **L'Art de la guerre**

Chaque histoire possède sa propre fonction `madlib()` et demande au joueur différents types de mots.
